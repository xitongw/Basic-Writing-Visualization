这个文件是一个单页面的写作过程可视化工具（Standalone Writing Process Visualization Tool） 。它被设计为一个独立的静态 HTML 文件，可以直接在浏览器中打开，无需后台服务器支持，非常适合部署在 GitHub Pages 或本地分享。

以下是它的核心功能和技术特点介绍：

### 1. 核心功能 (Core Features)
- 多格式数据支持 :
  - 支持上传原始的 log.json （包含按时间戳记录的键盘输入、删除、粘贴等详细日志）。
  - 支持上传预处理过的 _vis_data.json （句子级统计数据）或 log_timeline.json （时间轴数据）。
- 前端即时回放与分析 :
  - 工具内置了完整的日志解析引擎（从 Python 移植的 JavaScript 版本）。
  - 它能在浏览器端直接解析原始日志，重构写作过程，将字符流（Character Stream）还原为带有编辑历史的句子。
- 两种可视化视图 :
  - 句子编辑密度热力图 (Sentence Edit Density) :
    - 背景色深浅 : 根据句子的“编辑密度”（Edit Density = (插入字数+删除字数) / 最终字数）显示不同深浅的蓝色。编辑越多，颜色越深，直观展示写作时的“重灾区”或“精修区”。
    - 删除内容展示 : 被完全删除的句子会以灰色删除线形式保留在原本的位置，还原思考过程。
    - 粘贴内容高亮 : 识别日志中的 type: "paste" 事件，将粘贴的文本在句子中以 红色字体 高亮显示，区分于手动输入的文本。
  - AI 贡献分析 (AI Contribution) :
    - 根据日志中的标记，将句子分类为“AI 生成”（红色背景）、“AI 共创/修改”（蓝色背景）或“人类写作”（白色背景）。
### 2. 交互细节 (Interaction)
- 详细的悬浮提示 (Tooltip) :
  - 鼠标悬停在任意句子上，会显示该句子的详细统计数据：插入字数、删除字数、最终字数。
  - 版本历史 (Version History) : 展示该句子从创建到定稿的所有修改版本。每个版本都标记了时间戳和持续时长。
  - 差异对比 : 在版本历史中，增加的内容正常显示，删除的内容带有删除线，粘贴的内容显示为红色。
### 3. 技术亮点 (Technical Highlights)
- 纯静态架构 : 所有逻辑（HTML, CSS, JS）都封装在一个文件中（或通过构建工具内联），不需要 Python 后端，双击即可运行。
- 智能分句算法 : 能够根据标点符号自动将字符流切分为句子，并处理删除句子后的重组逻辑。
- 数据隐私 : 所有数据处理都在用户浏览器本地完成，不会上传到任何外部服务器。
### 4. 使用场景
- 写作研究 : 分析作者的修改习惯、停顿模式和重写策略。
- 教学反馈 : 向学生展示他们是在哪里花费了最多的精力进行修改。
- AI 辅助写作评估 : 直观地看到 AI 生成内容与人类原本想法的融合程度。
