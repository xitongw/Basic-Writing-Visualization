# 写作过程可视化工具 (Standalone Writing Process Visualization Tool)
该文件是一个单页面的写作过程可视化工具，被设计为独立的静态 HTML 文件，可直接在浏览器中打开，无需后台服务器支持，适配 GitHub Pages 部署或本地分享场景。

## 核心功能和技术特点
### 1. 核心功能 (Core Features)
- 多格式数据支持 :
  - 支持上传原始的 log.json（包含按时间戳记录的键盘输入、删除、粘贴等详细日志）。
  - 支持上传预处理过的 _vis_data.json（句子级统计数据）或 log_timeline.json（时间轴数据）。
- 前端即时回放与分析 :
  - 工具内置完整的日志解析引擎（Python 移植的 JavaScript 版本）。
  - 浏览器端直接解析原始日志，重构写作过程，将字符流（Character Stream）还原为带有编辑历史的句子。
- 两种可视化视图 :
  - 句子编辑密度热力图 (Sentence Edit Density) :
    - 背景色深浅 : 根据“编辑密度”（Edit Density = (插入字数+删除字数) / 最终字数）显示蓝色渐变，颜色越深代表修改越频繁，直观展示写作“重灾区/精修区”。
    - 删除内容展示 : 完全删除的句子以灰色删除线形式保留在原位置，还原思考过程。
    - 粘贴内容高亮 : 识别 type: "paste" 事件，粘贴文本以红色字体高亮，区分手动输入内容。
  - AI 贡献分析 (AI Contribution) :
    - 根据作者手动标识的日志标记，将句子分类：
      - AI 生成：红色背景
      - AI 共创/修改：蓝色背景
      - 人类写作：白色背景

### 2. 交互细节 (Interaction)
- 详细的悬浮提示 (Tooltip) :
  - 鼠标悬停句子时，显示该句子的插入字数、删除字数、最终字数等详细统计数据。
  - 版本历史 (Version History) : 展示句子从创建到定稿的所有修改版本，每个版本标记时间戳和持续时长。
  - 差异对比 : 版本历史中，新增内容正常显示，删除内容带删除线，粘贴内容显示为红色。

### 3. 技术亮点 (Technical Highlights)
- 纯静态架构 : 所有逻辑（HTML, CSS, JS）封装在单个文件（或构建工具内联），无 Python 后端依赖，双击即可运行。
- 智能分句算法 : 根据标点符号自动切分字符流为句子，处理删除句子后的重组逻辑。
- 数据隐私 : 所有数据处理在浏览器本地完成，无外部服务器上传行为。

### 4. 使用场景
- 写作研究 : 分析作者的修改习惯、停顿模式和重写策略。
- 教学反馈 : 向学生展示其在写作中花费最多精力修改的部分。
- AI 辅助写作评估 : 直观呈现 AI 生成内容（作者手动标识）与人类想法的融合程度。
